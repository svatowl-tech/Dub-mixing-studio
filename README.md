# Dub Mixing Studio (DubStudio Pro) 🎙️🎚️

**Dub Mixing Studio** — профессиональная кроссплатформенная цифровая звуковая рабочая станция (DAW) и среда пост-продакшена, созданная специально для студий озвучивания, фандаба, локализации аниме/кино, дубляжа и создания аудиокниг.

Программа объединяет в себе сверхточную многодорожечную запись, встроенный ИИ-конвейер разделения и очистки звука (UVR / Demucs / MDX-Net), автоматический конечный автомат сведения (Auto-Mixing Pipeline), прецизионный синхронизатор липсинка, интерактивный суфлер и расширенный экспорт в вещательные стандарты (BWF / EBU R128).

## 🌟 Что нового в версии 1.2.0

В версии **1.2.0** приложение совершило масштабный переход от базового трекера дублей к полноценной профессиональной нативной рабочей станции для комплексной обработки речи и дубляжа:

- **Автономный нативный конвейер сведения (Tokio Pipeline State Machine):** 4-фазный многопоточный автомат сквозного сведения дубляжа (Предобработка ➔ Синхронизация тайминга ➔ Сведение и авто-FX ➔ Мастеринг).
- **Встроенный менеджер нейросетевых моделей (UVR AI Models):** загрузка и управление моделями денойза, дереверберации и разделения стемов (MDX-Net, Roformer, BS-Roformer, VR Arch, Demucs) с докачкой через HuggingFace и проверкой SHA256.
- **Мастер-рэк вокальной шины (Vocal Bus 8-Stage DSP):** каскадный HPF, деэссер с упреждающим детектором (Lookahead), динамический эквалайзер, двухкаскадный Opto/VCA компрессор, сатуратор и лимитер без задержки.
- **Умное выравнивание тайминга (Smart Align):** автоматическое сведение по времени дубляжа с оригинальной речью с использованием алгоритмов GCC-PHAT, FastDTW и растяжения WSOLA без изменения высоты тона.
- **Иерархический движок волноформ (Mipmap Peak Pyramid):** моментальная отрисовка и навигация по многочасовым аудиофайлам с LOD-уровнями (1x, 10x, 100x, 1000x) и отсечением невидимых участков (Culling Engine) на 60 FPS.
- **Транзакционная история таймлайна (SQLx History Engine):** кольцевой буфер Undo/Redo на 200 действий с гарантией сохранения целостности проекта даже при аварийном закрытии.
- **Промышленный вещательный мастеринг:** 4-кратный True-Peak лимитер, измерение по стандарту EBU R128 / ITU-R BS.1770-4, TPDF-дизеринг и экспорт в Broadcast Wave Format (BWF) с метаданными `bext`.

## 🚀 Ключевые возможности

### 1. Автономный нативный конвейер сведения (Auto-Mixing Pipeline)
Встроенный конечный автомат оркестрации в Rust выполняет сведение проекта в фоне без блокировки интерфейса и без разрыва процесса:
* **Фаза 1: Предобработка и реставрация звука**
  * Нормализация громкости с контролем True-Peak.
  * Многопоточное Rayon-удаление щелчков и кликов (De-Click).
  * Нейросетевое удаление шума (UVR Denoise) и реверберации (UVR Dereverb).
  * Устранение взрывных согласных (De-Plosive) и адаптивный De-Esser.
  * Интеллектуальное выравнивание динамического диапазона (Speech Volume Leveler).
* **Фаза 2: Синхронизация и тайминг**
  * Определение пауз и активности речи (VAD Silence Split).
  * Smart Align: анализ взаимной корреляции (GCC-PHAT), матрица деформации времени FastDTW и алгоритм WSOLA для идеального попадания в оригинальный липсинк актера.
* **Фаза 3: Сведение и Авто-FX**
  * Спектральное согласование частотной характеристики с референсным треком (Match EQ).
  * Вокальный процессор Vocal Bus Rack.
  * Автоматический Sidechain Ducking фоновой музыки/интершума под речь с гладкими кривыми спада (Exponential / S-Curve).
* **Фаза 4: Мастеринг по вещательным стандартам**
  * Интегрированная громкость (Target LUFS от -14 до -23 LUFS).
  * Межсэмпловый True-Peak 4x Oversampling лимитер.
  * Дизеринг (TPDF) для экспорта в 16/24 бит.

### 2. Мультитрековая звукозапись и низколатентный движок
* **Двойной аудиодвижок:**
  * **Native Engine (Rust / CPAL):** прямой доступ к звуковым устройствам через **ASIO** (Windows) и CoreAudio/ALSA с минимальной задержкой.
  * **Web Audio Engine:** резервный кроссплатформенный режим для предпросмотра.
* **Smart Monitoring & Input FX:** встроенный мягкий нойз-гейт и лимитер для предотвращения клиппинга микрофона на входе.
* **Режим параллельной видеозаписи (Backstage Mode):** одновременная запись микрофона и веб-камеры (бэкстейджи, реакции, стрим-сессии) с автоматической синхронизацией дорожек.

### 3. Нейросетевое разделение источников (Source Separation)
* Интегрированный стек **audio-separator** и поддержка популярных архитектур:
  * **MDX-Net** (вокал, инструментал, реверберация, караоке).
  * **BS-Roformer / Mel-Band Roformer** (высококачественная изоляция диалогов и голоса).
  * **Demucs v4** (4/6-стемовое разделение: барабаны, бас, вокал, остальное).
  * **VR Architecture** (глубокая очистка от остаточного эха и шума помещения).
* Удобный менеджер моделей прямо в приложении: каталог, индикаторы загрузки, прогресс бар, проверка хэшей и удаление.

### 4. Работа с текстом, субтитрами и сценарием
* **Форматы субтитров:** импорт, парсинг, валидация и компиляция форматов **ASS**, **SSA**, **SRT**, **VTT**.
* **Импорт сценариев и книг:** прямая загрузка `docx`, `pdf`, `epub`, `fb2`, `txt`.
* **Умный суфлер (Smart Teleprompter):** интерактивный автоскролл, адаптирующийся под комфортную зону взгляда актера без дерганий.
* **Спектральный и смысловой контроль:** автоматический аудит скорости чтения (символов в секунду — CPS), детекция наложений реплик и расчет пауз между дублями.

### 5. Инструменты монтажа и таймлайн DAW
* **Ripple Editing & Crossfades:** умное подтягивание сегментов, защита от случайных микро-фрагментов при нарезке.
* **Waveform Mipmapping:** аппаратное кэширование пиков в 4 масштабах для мгновенного зумирования таймлайна любого масштаба.
* **Транзакционный Undo/Redo:** фиксация перемещений, склеек, регулировок громкости и настроек плагинов в локальной базе данных SQLite.
* **VST3 Host (экспериментальный):** сканирование и подключение внешних аудио-плагинов формата VST3.

### 6. Экспорт и подготовка релизов
* **BWF (Broadcast Wave Format):** экспорт дорожек со служебными блоками `bext` (таймкод смещения, информация об авторе, таймстемпы).
* **Экспорт стемов:** раздельный рендеринг сухих дорожек, обработанного вокала, интершума и мастер-микса.
* **FFmpeg Мультиплексор:** вшивание готового звука обратно в видеофайл без пережатия видеодорожки.
* **Аудит проекта (QA Audit):** автоматическая проверка перед сдачей релиза на клиппинг, фазовую корреляцию, пропущенные реплики и соответствие стандарту громкости заказчика.

## 💻 Сборка из исходного кода

### Требования к окружению
1. **Node.js** версии 20 или выше.
2. **Rust** (актуальная стабильная версия toolchain).
3. **C++ компилятор и системные библиотеки:**
   * **Windows:** Visual Studio C++ Build Tools.
   * **Linux (Ubuntu/Debian):**
     ```bash
     sudo apt-get update && sudo apt-get install -y \
       libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev \
       libssl-dev libayatana-appindicator3-dev librsvg2-dev libasound2-dev
     ```
   * **macOS:** Xcode Command Line Tools.

### Инструкция по сборке

```bash
# 1. Клонирование репозитория
git clone https://github.com/svatowl-tech/Dub-mixing-studio.git
cd Dub-mixing-studio

# 2. Установка зависимостей (автоматически скачает ffmpeg и подготовит окружение)
npm install

# 3. Настройка ASIO SDK для Windows (опционально, для низкой задержки)
npm run setup:asio

# 4. Запуск в режиме разработки с живой перезагрузкой
npm run tauri dev

# 5. Сборка продакшен-релиза
npm run tauri build
```
